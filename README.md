# تحكم الأطفال (Kids Control)

تطبيق أندرويد يحدّ من استمرار مشاهدة **يوتيوب** و**الألعاب** لمدة تحددها أنت.
عند انتهاء الوقت تُقفل الشاشة بطبقة لا تُفتح إلا **ببصمة ولي الأمر**.
لا يمكن تعديل الإعدادات إلا بعد إدخال **رقم سري + بصمة**.

---

## كيف تبنيه وتثبّته على جوالك (خطوة بخطوة)

### المتطلبات
- حمّل **Android Studio** المجاني من: https://developer.android.com/studio
  (يأتي بكل ما يلزم: Java و Android SDK).

### الخطوات
1. افتح Android Studio، ثم: **File → Open** واختر مجلد المشروع هذا (`Kids control`).
2. انتظر حتى ينتهي من التحميل والمزامنة (Gradle Sync). أول مرة قد تأخذ 10–30 دقيقة لأنه يحمّل المكتبات.
   - إن ظهر طلب لتحميل أدوات (SDK / Build Tools) اقبلها.
3. وصّل جوال سامسونج بالكمبيوتر بكابل USB، وفعّل **خيارات المطور** و**تصحيح USB**:
   - الإعدادات → حول الهاتف → اضغط «رقم الإصدار» 7 مرات لتفعيل خيارات المطور.
   - الإعدادات → خيارات المطور → فعّل **USB debugging**.
4. في Android Studio اختر جوالك من الأعلى، ثم اضغط زر التشغيل ▶ (Run).
   - سيُبنى التطبيق ويُثبّت على جوالك مباشرة.
   - أو لإخراج ملف APK: **Build → Build Bundle(s)/APK(s) → Build APK(s)**، وتجده في
     `app/build/outputs/apk/debug/app-debug.apk`.

---

## أول تشغيل على الجوال
1. افتح التطبيق، وأنشئ **رقماً سرياً** (4 أرقام على الأقل)، ثم أكّد بالبصمة.
2. حدّد مدة يوتيوب ومدة الألعاب (بالدقائق) واضغط **حفظ**.
3. امنح الصلاحيتين المطلوبتين (التطبيق يفتح لك شاشة كل صلاحية):
   - **الوصول إلى بيانات الاستخدام** (Usage Access) — ليعرف أي تطبيق مفتوح.
   - **العرض فوق التطبيقات** (Display over other apps) — لإظهار شاشة القفل.
4. اضغط **تشغيل المراقبة**.

> ملاحظة سامسونج: من الإعدادات → البطارية → ضع التطبيق في قائمة
> «التطبيقات غير الخاملة / عدم التحسين» حتى لا يوقفه النظام في الخلفية.

---

## كيف يعمل
- يراقب التطبيق المفتوح كل ثانيتين.
- يحتسب وقت الاستخدام المتواصل ليوتيوب وللألعاب كلٌّ على حدة.
- **التحايل بالخروج والدخول السريع ممنوع**: لا يُعاد تصفير العدّاد إلا بعد ابتعاد
  الطفل عن التطبيق مدة «الراحة» التي تحددها (افتراضياً 60 ثانية).
- عند بلوغ الحد: تظهر شاشة قفل سوداء تغطي كل شيء، ولا تزول إلا ببصمتك.
  بعد البصمة يُمنح الطفل فترة جديدة كاملة.
- الألعاب تُكتشف تلقائياً (التطبيقات المصنّفة «لعبة» في المتجر).

## ملاحظات
- التطبيق للاستخدام العائلي الخاص، وليس للنشر على المتجر.
- غيّر الرقم السري من داخل الإعدادات (زر «تغيير الرقم السري»).
- معرّف التطبيق: `com.almurshid.kidscontrol`.
